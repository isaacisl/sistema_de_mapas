Como montar sua planilha

Sua planilha precisa ter pelo menos 2 colunas:

Colunas necessárias
1. Código IBGE
Código numérico que identifica a área geográfica:
• 7 dígitos → município  5300108 (Brasília)
2. Coluna de dados a plotar
Qualquer coluna numérica ou categórica que deseja visualizar no mapa
(ex: população, receita, índice, quantidade, filiado, porte).
Exemplo de planilha válida
cod_ibge municipio populacao porte
5300108 Brasília 3015268 Grande
3550308 São Paulo 12396372 Pequeno
3304557 Rio de Janeiro 6747815 Grande
1302603 Manaus 2219580 Médio
Dicas importantes
📋 Código IBGE
  • O nome da coluna de código IBGE pode ser qualquer um
  • A coluna de código IBGE deve conter apenas números
📁 Arquivo
  • Aceita .csv, .xlsx, .xls e .xlsm
  • Para CSV, use vírgula (,) ou ponto-e-vírgula (;) como separador
🔢 Dados e agregação
  • Pode ter várias linhas por município — elas serão agregadas (soma, média, etc.)
  • Municípios sem dado aparecem em cinza no mapa
Entendendo os Tipos de Cálculo

Estes cálculos são usados quando a sua planilha possui várias linhas para o mesmo local. O sistema precisa saber como juntar esses valores em um só para colorir o mapa.

Soma (Total)
Soma todos os valores numéricos encontrados para o mesmo local.
Exemplo de uso: Você tem uma planilha com a receita de várias empresas por município e deseja mostrar a receita total daquele município.
Empresa AR$ 10
Empresa BR$ 15
ResultadoR$ 25
Média
Calcula a média aritmética dos valores de um mesmo local.
Exemplo de uso: Sua planilha contém a nota do IDEB de várias escolas da mesma cidade, e você quer colorir o mapa pela nota média das escolas.
Escola 1Nota 6.0
Escola 2Nota 8.0
ResultadoNota 7.0
Máximo e Mínimo
Pega apenas o maior ou o menor valor encontrado.
Exemplo de uso: Você tem as temperaturas diárias de um mês inteiro para um município, e deseja exibir o pico de calor (máximo) do mês.
Dia 132°C
Dia 235°C
Máximo35°C
Contagem
Ignora a coluna de valor numérico e apenas conta quantas linhas (registros) existem para aquele local.
Exemplo de uso: Você tem uma lista de acidentes de trânsito. Sem usar uma coluna de "valor", você escolhe contagem para ver quantas ocorrências existiram.
Acidente 1-
Acidente 2-
Resultado2 ocorrências
Tipos de Visualização
Calor (Gradiente)
Cada área recebe uma cor proporcional ao seu valor numérico — quanto maior, mais escura. Ideal para visualizar intensidade, como população, receita ou índices.
Baixo
Alto
Categórico (por grupo)
Cada categoria recebe uma cor distinta. Ideal para colunas de texto como porte, região, partido, tipo de gestão. Você pode personalizar a cor de cada categoria.
Grande Médio Pequeno Micro Nano
Distribuição de Cores
Linear
A cor avança proporcionalmente ao valor. Se o valor dobra, a posição na escala também dobra. Funciona bem quando os dados estão bem distribuídos e sem valores extremos dominantes.
Proporcional (Rank)
Cada faixa de cor representa o mesmo percentual de municípios (ex: 20% por cor). Ideal quando poucos valores muito altos dominam o mapa e deixam o restante invisível.
Logarítmica
Comprime os valores altos e expande os baixos. Municípios com valores menores ganham mais destaque visual. Ideal para dados com grande amplitude, como população.
Paletas de Cores

Escolha a paleta de acordo com o tipo de dado. Sequenciais (uma cor) são ideais para valores numéricos crescentes. Divergentes (duas cores) funcionam bem quando há um valor central de referência (ex: positivo/negativo).

Sequenciais — para dados numéricos com uma direção
Azul
Clássico para dados de intensidade. Ótimo para população, arrecadação, IDH.
Vermelho
Transmite urgência ou risco. Ideal para indicadores negativos, inadimplência, mortalidade.
Verde
Associado a crescimento e resultado positivo. Bom para cobertura, adesão, receita.
Laranja
Energético e vibrante. Bom para dados de atividade econômica, produção.
Roxo
Sofisticado e neutro. Bom para dados demográficos ou quando outras cores já foram usadas.
Amarelo → Vermelho
Intuitivo para risco crescente: verde-amarelo (seguro) até vermelho (crítico).
Amarelo → Azul
Elegante e com bom contraste. Ótimo para dados ambientais e climáticos.
Vermelho → Roxo
Vibrante e moderno. Bom para dados de saúde ou quando se quer destaque visual.
Perceptualmente uniformes — alta legibilidade
Viridis
Acessível para daltônicos. Muito usado em publicações científicas e acadêmicas.
Plasma
Alta saturação e contraste. Ótimo para apresentações com fundo escuro ou impacto visual.
Divergentes — para dados com valor central de referência
Frio → Quente
Azul para valores abaixo da média, vermelho para acima. Ideal para variações em relação à média nacional.
Vermelho → Verde
Vermelho para ruim, verde para bom. Perfeito para rankings, notas e indicadores de desempenho.
O que selecionar como dado do mapa?

Escolha a coluna cujos valores vão colorir cada área do mapa. Veja os três casos mais comuns:

Coluna numérica — valores contínuos
Quando os números têm grandeza (população, receita, índice…). O mapa usa gradiente de cor — quanto maior o valor, mais escura a área.

Quando o valor indica apenas se algo existe ou não naquela área (filiado, conveniado, certificado…).

Coluna categórica — grupos ou classificações
Quando o valor é um texto que representa uma categoria (porte, partido, região, tipo de gestão…). Cada grupo recebe uma cor distinta.
