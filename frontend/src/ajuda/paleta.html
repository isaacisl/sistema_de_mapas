Escolha a paleta de acordo com o tipo de dado. Sequenciais (uma cor) são ideais para valores numéricos crescentes. Divergentes (duas cores) funcionam bem quando há um valor central de referência (ex: positivo/negativo).

Sequenciais — para dados numéricos com uma direção
Azul
Clássico para dados de intensidade. Ótimo para população, arrecadação, IDH.
Vermelho
Transmite urgência ou risco. Ideal para indicadores negativos, inadimplência, mortalidade.
Verde
Associado a crescimento e resultado positivo. Bom para cobertura, adesão, receita.
Laranja
Energético e vibrante. Bom para dados de atividade econômica, produção.
Roxo
Sofisticado e neutro. Bom para dados demográficos ou quando outras cores já foram usadas.
Amarelo → Vermelho
Intuitivo para risco crescente: verde-amarelo (seguro) até vermelho (crítico).
Amarelo → Azul
Elegante e com bom contraste. Ótimo para dados ambientais e climáticos.
Vermelho → Roxo
Vibrante e moderno. Bom para dados de saúde ou quando se quer destaque visual.
Perceptualmente uniformes — alta legibilidade
Viridis
Acessível para daltônicos. Muito usado em publicações científicas e acadêmicas.
Plasma
Alta saturação e contraste. Ótimo para apresentações com fundo escuro ou impacto visual.
Divergentes — para dados com valor central de referência
Frio → Quente
Azul para valores abaixo da média, vermelho para acima. Ideal para variações em relação à média nacional.
Vermelho → Verde
Vermelho para ruim, verde para bom. Perfeito para rankings, notas e indicadores de desempenho.
